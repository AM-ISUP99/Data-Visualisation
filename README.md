Bonjour et bienvenue sur notre projet de Data Visualisation. 

Ce projet a été réalisé dans le cadre d'un cours portant sur la Data Visualisation à l'ISUP.

Voici le lien de l'application streamlit en ligne ici : https://data-visualisation-projet-groupe-gbsm.streamlit.app/

Dans ce GitHub, vous retrouverez tout les éléments nécessaires afin de faire tourner le projet en local sur votre machine :
- .streamlit : contient le code couleur de la page
- data : contient les différentes données nécessaires au projet
- ne_110_m_admin_0_countries : contient les données .shp permettant de détourrer les pays sur la carte.
- Logo ISUP : le logo de l'ISUP qui s'affiche sur notre projet
- Untitled-2.ipynb : le notebook jupyter qui a permis de créer la carte ainsi que sa configuration
- **dashboard.py :** le fichier principal de ce projet, contient tout le code nécessaire à l'éxécution du projet
- kepler_config.py : contient la configuration de la carte, cad les codes couleurs, sa taille, les données à afficher etc...
- requirements.txt : fichier permettant à streamlit de télécharger les packages afin que le site fonctionne en ligne

Pour utiliser le dashboard en **local**, il vous suffira de télécharger ce GitHub, de tout mettre dans un dossier, de télécharger **Visual Studio Code**, d'ouvrir le dossier dans lequel vous avez placé les fichiers du GitHub sur VSC, de télécharger les packages nécessaires à l'aide de votre Terminal, ainsi que de vous placer dans le bon dossier et enfin de lancer le dashboard avec la commande suivante : **streamlit run dashboard.py**.
